# mastpart.3
In Part 3, I improved the Chef’s Menu Manager application by adding more features and improving its functionality compared to Part 2. In Part 2, the application allowed the chef to add and view menu items. In Part 3, I added the ability to edit and delete existing dishes, search for specific dishes, and filter menu items according to their course, such as starters, main courses and desserts. I also added a dashboard that displays the total number of dishes, the average price and the number of dishes in each course. Input validation was introduced to prevent users from submitting incomplete or incorrect information. In addition, I implemented AsyncStorage so that menu items are saved on the device and remain available when the application is closed and reopened. These changes made the application more user-friendly, organised and efficient.
